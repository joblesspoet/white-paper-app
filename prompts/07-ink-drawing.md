# Session 07 — Ink drawing

Read docs and inspect the viewport implementation. Implement only freehand drawing tools.

Define an ink stroke object and render strokes in Skia. Add pen, highlighter, color, width, opacity, and eraser behavior. Ensure drawing coordinates remain correct while zoomed and panned. Add tool options in a compact sheet or popover, clear active states, and accessible controls. Do not implement text, shapes, persistence, or OCR. Test drawing, zoomed drawing, erasing, and tool changes. Run app/typecheck/lint and update task status; next task is undo/redo.
