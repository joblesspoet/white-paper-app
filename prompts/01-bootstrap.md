# Session 01 — Bootstrap

Read the project docs and inspect the current directory before changing anything. Work only in the current project root.

Create the Expo React Native TypeScript app in the current directory. Preserve `README.md`, `docs/`, `design-system/`, and `prompts/`. Do not overwrite planning files. Use the Expo-managed workflow and install only dependencies required for a clean foundation: Expo, React Native, TypeScript, status bar, and safe-area support. Do not implement navigation, canvas, auth, AI, OCR, persistence, or screens beyond the default startup screen.

Run the app and verify it starts. Run typecheck and lint if configured. Inspect the diff. Update `docs/task-status.md` with completed work, files changed, verification results, known issues, and next task: navigation. Stop after bootstrap.
